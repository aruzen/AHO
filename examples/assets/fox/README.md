# Fox

Source: [Khronos glTF-Sample-Assets, pinned revision](https://github.com/KhronosGroup/glTF-Sample-Assets/tree/15cd02d304e54cb42a4db4eefe719f76190f4b68/Models/Fox).
`Fox.glb`, `LICENSE.md` and `metadata.json` are copied without changes.
The viewer defaults to the model's **Run** skeletal animation. Walk and Survey are also included.

- Model: PixelMannen, 2014, CC0-1.0.
- Rigging & Animation: tomkranis, 2014, CC-BY-4.0.
- Conversion to glTF: @AsoboStudio and @scurest, 2017, CC-BY-4.0.
- Metadata: CC-BY-4.0. See LICENSE.md and metadata.json for the original notices and license links.

Only the directory layout differs from the source repository. The viewer generates missing normals in memory; the asset remains unchanged.
