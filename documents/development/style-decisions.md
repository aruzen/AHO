# 未確定の規約

確定済みの命名・配置規則は[style-checks.md](style-checks.md)の検査対象です。次の項目は独自の新規ルールを設けず、ユーザーとの決定後に検査設定へ反映します。

concept名のsnake_caseと、クラス内定義の5コード行基準は確定済みです。concept用の命名検査設定は、現在はまだ有効にしていません。

| 項目 | 確認する内容 |
| --- | --- |
| template引数 | 型・template・値の引数をそれぞれどう命名するか |
| マクロ | 定数・関数形式、内部用接頭辞をどう分けるか |
| ローカルのthread_local変数 | 通常のローカル変数か、static変数に準じるか |
| ユーザー定義リテラル | サフィックスの命名と略語の扱い |
| ファイル・ディレクトリ名 | snake_case、型名との対応、2d等の数字表記 |
| 型内の宣言順序 | 型・変数・コンストラクタ・関数とpublic/protected/privateの具体的な並び |
| 定義が先に必要な関数 | auto戻り値の型推論やconsteval等で、型定義より前に関数本体が必要な場合の例外 |
| 末尾の`_` | 衝突時に使う規則は確定済み。衝突の根拠をどう記録して機械検査するか |
| 外部契約の例外 | STL/GTest等の許可を識別子単位から所属スコープ単位へ絞るか |
| 検査範囲 | アプリ・未使用ヘッダー・他OS分岐・マクロ生成コードまで継続検査へ含めるか |

コメントの日本語・コードの読みやすさ・長い式の適切な分割は、現在の機械検査だけでは判定しません。
